Idea 07 · Recovery

Pick up exactly where they stopped.

Inside the PWA, registration and verification save every answer as a state while the user types. If they leave, an email brings them back to the same screen, with everything still filled in.

How it works
  1. 1
    TypeEach answer in registration or verification is written to a saved state.
  2. 2
    LeaveThe state keeps the last screen and every value entered so far.
  3. 3
    EmailA reminder names that screen. Its button is a link to it, carrying the state.
  4. 4
    ReturnThe link opens the PWA on that screen with the answers filled in.
