        Why this is safe

        Easier for customers. Not easier to abuse.

        Four guard rails sit behind the friendlier screen.

        10min

        Short expiry

        Code and link both expire quickly. Today’s link stays live for 24 hours.

        1use

        Single-use

        Once verified, the code and the link stop working. A new request voids the old one.

        5tries

        Attempt limits

        Five wrong codes pause entry. Resends are rate-limited to one every 30 seconds.

        1session

        Same-session binding

        The code is tied to the sign-up that requested it, so a forwarded code is useless elsewhere.

        Illustrative values for the prototype. Final limits to be set with Security.
