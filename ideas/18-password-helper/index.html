Guardrails

Built so it is safe to send in an email

Generated on the device

Passwords are created in the recipient’s browser with a secure random source. XM never sees or stores them.

Nothing sensitive in the email

The message holds a link and the widget, not a ready-made password. The link carries the email only, and expires.

Graceful fallback

AMP for Email in supporting clients, a hosted page everywhere else. One widget, two surfaces.

Password manager friendly

The field uses the new-password hint, so managers can offer to save it after the first use.
